# FAIR-D / CARE-D documented governance dataset for Indigenous-language digital resources in Mexico

Research data accompanying the manuscript **“Beyond openness: FAIR, CARE, and documented Indigenous data governance in digital language infrastructures in Mexico.”**

## DOI
The archival DOI for version 1.0 is https://doi.org/10.5281/zenodo.22288377. Cite this DOI for the stable archived version; the GitHub directory remains the development/source mirror.

## Contents
- `data/fair_care_matrix_main_sample.csv` — the 12 resources used in the main descriptive analysis.
- `data/fair_care_matrix_all_cases.csv` — all documented cases, including excluded/sensitivity cases.
- `docs/codebook_v1.md` — frozen coding instrument.
- `docs/source_audit.md` — primary-source and academic-reference audit.
- `scripts/check_summary.py` — reproduces the manuscript's principal descriptive statistics.
- `CITATION.cff` — citation metadata.
- `LICENSE` — CC BY 4.0 licence for this original coding dataset and documentation.

## Scope and caution
The scores measure **public documentary visibility**, not substantive ethical compliance. A zero means that evidence was not located in the reviewed public documentation as of 20 August 2026; it does not prove that the corresponding practice was absent.

The main sample contains 12 resources selected intentionally for maximum variation. It is descriptive and is not statistically representative of all Indigenous-language digital resources in Mexico.
