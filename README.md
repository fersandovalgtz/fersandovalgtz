## Proyecto destacado · Featured project

### [Rarámuri Digital](https://github.com/fersandovalgtz/raramuri-digital)

**Infraestructura lexicográfica rarámuri–español para investigación, docencia, humanidades digitales y desarrollo de aplicaciones.**

Rarámuri Digital publica un conjunto de datos lexicográficos reproducible con **2,581 entradas**, identificadores persistentes, trazabilidad documental y exportaciones en formatos interoperables. El proyecto incluye API pública, documentación científica, mecanismos de gobernanza y un depósito citable con DOI.

- **Repositorio:** [github.com/fersandovalgtz/raramuri-digital](https://github.com/fersandovalgtz/raramuri-digital)
- **Sitio y consulta:** [raramuri.ceees.mx](https://raramuri.ceees.mx)
- **Dataset y DOI:** [10.5281/zenodo.21483353](https://doi.org/10.5281/zenodo.21483353)
- **API:** [OpenAPI 3.1](https://raramuri.ceees.mx/api/openapi)
- **Formatos:** CSV · JSON · XML · SQL · TEI Lex-0 · OpenAPI

> La publicación del recurso está autorizada para difusión; la validación lingüística comunitaria permanece pendiente. El proyecto distingue entre disponibilidad técnica, procedencia documental y autoridad lingüística de las comunidades hablantes.

**Si Rarámuri Digital resulta útil para investigación, docencia o desarrollo, puede citar el DOI y marcar ⭐ el repositorio para mejorar su descubrimiento.**
